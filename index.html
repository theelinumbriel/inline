inline

edit the text on any page, in place. one file, no dependencies.

…or add ?edit to the url, or press ⌘/Ctrl + Shift + E. click any line below, type, and watch the toolbar count your edits. hit copy changes to get the JSON. reload — your edits stick (they live in this browser).

a little demo

edit any of this →

this paragraph is editable. so is the heading above it, and the caption.

inline only ever touches the text — your tags, links, and layout are left exactly as they were.

drop it in

<script src="inline.js"></script>

that's the whole install. then enable edit mode any of three ways:

?edit            # add to the url
⌘/Ctrl+Shift+E   # keyboard toggle
Inline.toggle()  # from the console / your own button

how it works

every leaf line of text becomes contenteditable (plaintext-only, so markup can't be mangled). edits are saved to localStorage, keyed by a stable path, and re-applied on every load — so they persist in your browser. copy changes hands you a JSON map of { "selector": "new text" } to paste back into your source and commit.

configure

<script src="inline.js"
  data-selector="h1,h2,p,li"   <!-- which elements are editable -->
  data-auto="1">              <!-- start in edit mode -->
</script>

mark anything you don't want touched with data-inline-skip.
